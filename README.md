# A Simple project that allows a user to download there emails from a service

## This may be of use if you have ran out of storage for a service, like a member of my family has, and need to delete emails to save space

## Use

1. Create a .env with the same format as the .env.example
2. run cargo run on the code (make sure rust is running)
3. download emails from a server

# Issues

- probably not secure
- i've only tested it with a few emails
- for some services, it limits at 10000 emails (although probably just a provider being annoying with rate limits)

Enjoy :)
